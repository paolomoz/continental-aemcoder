# table

Custom **table** block. Purpose: data-table.

## Authoring (Document Authoring)

Model: `collection`

Repeating rows — one row per item. Each item: each block row = one table row; each cell = one table cell (inline formatting such as bold, line breaks and links is preserved; empty cells are kept). The first row becomes the table head unless the 'no header' option is set.

## Supported variations

| Variation | Option class |
| --- | --- |
| No header row | `no header` |
| Striped | `striped` |
